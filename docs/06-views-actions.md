### 2.2 ตัวอย่างการใช้งานจริง 5 แบบ

**(1) อนุมัติราคา — `SET_COLUMN_VALUE` + เงื่อนไขสิทธิ์**

`อนุมัติ` บน `ข้อมูลการวางบิล` (หน้า 1816)
| ฟิลด์ | ค่า |
|---|---|
| Do this | `SET_COLUMN_VALUE` |
| Attach to column | `สถานะการอนุมัติ` |
| Set this column | `สถานะการอนุมัติ` = `="อนุมัติ"` |
| Only if | `=AND( [สถานะการอนุมัติ] <> "อนุมัติ", USERROLE() = "ADMIN")` |
| Modifies data | Yes |

คู่กับฟอร์แมตรูล `อนุมัติ` (ตัวหนาสีเขียว + ไอคอน ✓) และสูตร `ราคาที่อนุมัติแล้ว`

**(2) ดูแผนที่ — `NAVIGATE_APP` ที่ผูกกับคอลัมน์พิกัด**

`View Map (จุดส่งสินค้าปลายทาง)` บน `SCGนครหลวงJWDภูมิภาค` (หน้า 1859)
- Attach to column: `จุดส่งสินค้าปลายทาง` · Only if: `NOT(ISBLANK([จุดส่งสินค้าปลายทาง]))`
→ ปุ่มจะโผล่เฉพาะแถวที่มีพิกัด

**(3) ส่งรูปข้ามแอป — `NAVIGATE_DIFFERENT_APP`**

`ส่งรูปแจ้งปั ญหา` บน `แจ้งปั ญหาระหว่างวัน` (หน้า 1863) — ใช้ร่วมกับคอลัมน์
`LINK_Image_แจ้งปั ญหา` ที่สร้าง URL รูปด้วย `ENCODEURL` (หน้า 227)

**(4) ส่งออกข้อมูล — `EXPORT_VIEW`**

`ข้อมูลการวางบิลcsv`, `ตารางงานประจำวันcsv`, `ข้อมูลพนักงานcsv`,
`ข้อมูลชื่องานต้นทางปลายทางcsv` (หน้า 1894–1897) — เงื่อนไข `true` (ใช้ได้เสมอ)

**(5) สั่งบอททำงาน — `COMPOSITE`**

`ปริ๊นวางบิลทุกงาน` บน `ปริ๊นใบวางบิล` (หน้า 1880) — เรียก 13 บอทเรียงกัน คั่นด้วย `Clear` 12 ตัว

| 4 | `FILTER` | ตั้งช่วงวันที่ + สั่งส่งออก | `EXPORT TO PDF`, `EXPORT TO Excel(สรุปจำนวนจุดส่งงาน)` |
| 5 | `สรุปเบิกส่วนต่าง` | ตรวจยอดเบิกส่วนต่างก่อนออกเอกสาร | `Export to Excel` |
