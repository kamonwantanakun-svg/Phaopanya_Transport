## 2. รูปแบบสูตรที่พบบ่อย

### 2.1 แนวทางการดึงข้อมูลข้ามตาราง (4 แนวทาง)

| แนวทาง | ฟังก์ชัน | ใช้เมื่อ | ผลลัพธ์ | จำนวนสูตร |
|---|---|---|---|---:|
| ดึง **ค่าเดียว** | `LOOKUP` | มีคีย์เดียวที่ตรงแน่นอน | ค่าเดียว (Price/Text/Number) | 106 |
| ดึง **ชุดแถว** | `FILTER` | ต้องการทุกแถวที่ตรงเงื่อนไข | คอลัมน์ List | 16 |
| ดึง **คอลัมน์ตามเงื่อนไข** | `SELECT` (+ `ANY`/`COUNT`/`SUM`/`MIN`) | ต้องนับ/รวม/หาค่าต่ำสุดจากชุดแถว | ตัวเลข | 31 |
| ดึง **แถวที่อ้างกลับ** | `REF_ROWS` | ต้องการดู “ใครอ้างถึงฉัน” | คอลัมน์ List | 16 |

**ตัวอย่าง (1) — `LOOKUP` ดึงราคาจริงตาม Shipment**

`ข้อมูลการวางบิล` → `ราคาก่อนส่งสินค้า` (App formula) — `[data/formulas/formulas.csv]`
```
=LOOKUP([_THISROW].[Shipment No],"ราคาในระบบก่อนส่ง สินค้า","Shipment No","ราคา")
```

**ตัวอย่าง (2) — `LOOKUP` + `USEREMAIL()` ผูกแถวกับผู้ใช้ที่ล็อกอิน**

`ข้อมูลการวางบิล` → `ID_พนักงาน` (Initial value)
```
=LOOKUP(USEREMAIL(), "ข้อมูลพนักงาน", "Email พนักงาน", "ID_พนักงาน")
```

**ตัวอย่าง (3) — `SELECT` + `ANY` lookup แบบช่วงค่า 2 มิติ**

`ข้อมูลการวางบิล` → `ราคาตามระยะทาง` (App formula) — ยืนยันเต็มจาก PDF หน้า 136
```
=ANY( SELECT( Price_Table[Price], AND( IN( [_THISROW].[ชื่องาน], SPLIT([ชื่องาน], ",") ),
[เรทน้ำมัน_Minimum] <= [_THISROW].[เรทดีเซล], [เรทน้ำมัน_Maximum] >= [_THISROW].[เรทดีเซล],
[ระยะทาง_Minimum] <= [_THISROW].[ระยะทางที่วิ่ง (KM)],
[ระยะทาง_Maximum] >= [_THISROW].[ระยะทางที่วิ่ง (KM)] ) ) )
```

**ตัวอย่าง (4) — `FILTER` ดึงชุดแถวมาเป็น List**

`สรุป_Shipment` → `รายการ_รอสแกน` (App formula)
```
=FILTER( "ตารางงานประจำวัน", AND( [Shipment No] = [_THISROW].[ShipmentNo],
OR( ISBLANK([ScanStatus]), [ScanStatus] <> "สแกนรับแล้ว" ) ) )
```

**ตัวอย่าง (5) — `FILTER` คีย์ “ชื่องาน + ช่วงวันที่” (ใช้กับงานเอกสาร)**

`สร้างเอกสาร` → `ปริ๊นใบวางบิล` (App formula) — ยืนยันเต็มจาก PDF หน้า 443
```
=FILTER("ข้อมูลการวางบิล",(AND([ชื่องาน]=[_THISROW].[ชื่องาน],
[วันที่]>=[_THISROW].[StartDate],[วันที่]<=[_THISROW].[EndDate])))
```

**ตัวอย่าง (6) — `REF_ROWS` (รูปแบบเดียวกัน 16 คอลัมน์)**

`ข้อมูลพนักงาน` → `Related …s` 7 คอลัมน์
```
REF_ROWS("ข้อมูลการวางบิล", "ID_พนักงาน")
REF_ROWS("แจ้งปั ญหาระหว่างวัน", "ID_พนักงาน")
REF_ROWS("ScanDocs", "Invoice_No")
```

### 2.3 รูปแบบที่พบเฉพาะในแอปนี้

**คีย์เดือนแบบ พ.ศ.** (คอลัมน์ `เดือน` ใน 9 ตาราง) ใช้สูตรเดียวกันทั้งหมด:
```
=IF( ISBLANK([วันที่ส่งสินค้า]), "", CONCATENATE(
YEAR([วันที่ส่งสินค้า]) - IF(YEAR([วันที่ส่งสินค้า]) > 2500, 543, 0),
"-", TEXT([วันที่ส่งสินค้า], "MM") ) )
```
ใช้ใน `SCGนครหลวงJWDภูมิภาค`, `ข้อมูลการวางบิล`, `ข้อมูลการเข้าบำรุงรักษา`, `ข้อมูลงานRT`,
`ตารางงานประจำวัน`, `ทำเบิกส่วนต่างScgวังน้อย`, `รับงานคืนได้เงิน200`,
`ราคาในระบบก่อนส่งสินค้า`, `แจ้งปั ญหาระหว่างวัน` — `[data/columns/all_columns.csv]`

|---|---|---|---:|
| `ข้อมูลการวางบิล.ราคา` | Initial value | ชื่องานว่าง / ราคาคงที่ / ราคาในระบบ / ราคาตามระยะทาง | 119 |
| `ข้อมูลการวางบิล.ราคาจุดเพิ่ม` | App formula | ชื่องาน: เบทาโกร+เหมาตู้ / ไอโรบอท / ออเรนจ์โคร / เอเทน | 134 |

(`ID_งานประจำวัน`, `ID_วางบิล`, `ID_สแกน…`, `Row ID`, `ID_พนักงาน`, `ID_ประกาศ`, `ID_รับทราบ` ฯลฯ)
