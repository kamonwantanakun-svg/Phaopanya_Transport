# 04 — คอลัมน์: คอลัมน์สำคัญรายโดเมน และชนิดคอลัมน์ทั้งหมด 113 แถว

> ไฟล์ที่ 4 จาก 10 · แหล่งหลัก `[data/columns/all_columns.csv]` (2,304 แถว) และ `[data/columns/by-type.csv]` (113 แถว)

---

## 1. วิธีอ่านคอลัมน์หนึ่งแถว

ไฟล์ `all_columns.csv` มี 22 คอลัมน์ คีย์ที่ต้องรู้:

| ฟิลด์ | ความหมาย | หมายเหตุ |
|---|---|---|
| `table_name`, `column_name` | คอลัมน์นี้อยู่ในตารางไหน | ผูกถูกต้อง 2,304/2,304 แถว (ตรวจแล้ว) |
| `type` | ชนิดข้อมูล | **354 แถวมี JSON ติดมาด้วย** (ดูหัวข้อ 4) |
| `key` / `part_of_key` | คีย์หลัก/คีย์รอง | ใช้ทำ join ระหว่างตาราง |
| `app_formula` | สูตรคำนวณใหม่ทุกครั้ง (read-only) | **คำนวณชี้** |
| `initial_value` | ค่าเริ่มต้นตอนสร้างแถว (แก้ได้ทีหลัง) | **คำนวณชี้ (แบบแก้ได้)** |
| `valid_if` / `required_if` / `editable_if` / `show_if` / `reset_if` | กฎสิทธิ์/ตรวจสอบระดับคอลัมน์ | ดู `08-security-rules.md` |
| `error_message_if_invalid` | ข้อความแจ้งเตือนเมื่อค่าไม่ผ่านเงื่อนไข | 31 คอลัมน์ |
| `doc_page` | เลขหน้าใน PDF ต้นฉบับ | ใช้ยืนยันกลับ (ดู `10-known-issues.md`) |

> **คำสำคัญ:** `app_formula` กับ `initial_value` อยู่ในช่องเดียวกันของ AppSheet แต่คนละเรื่อง —
> App formula คำนวณใหม่เมื่อข้อมูลอ้างอิงเปลี่ยน ส่วน Initial value คำนวญครั้งเดียวตอนสร้างแถว
> แล้วค่าจะ **ไม่** เปลี่ยนตาม

## 2. คอลัมน์สำคัญรายโดเมน

สัญลักษณ์: 🔢 = คำนวณชี้ (App formula) · ✏️ = ค่าเริ่มต้นที่แก้ได้ (Initial value) · ⬜ = กรอกเอง
ทุกชื่อคอลัมน์มาจาก `[data/columns/all_columns.csv]`
