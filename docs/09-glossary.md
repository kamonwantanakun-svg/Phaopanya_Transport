# 09 — อัจฉรัยศัพท์: ไทย ↔ อังกฤษที่ใช้จริงในแอป

> ไฟล์ที่ 9 จาก 10 · ทุกคำอธิบายผูกกับ **ชื่อตาราง/คอลัมน์ที่มีอยู่จริง** ใน `[data/]`
> ถ้าคำใดไม่ปรากฏในข้อมูล จะเขียนกำกับว่า **“ข้อมูลในเอกสารไม่ระบุ”** — ดูหัวข้อ 5 เรื่องนี้

---

## 1. ศัพท์กระบวนการหลัก

| ไทย | อังกฤษ | หมายถึงในแอปนี้ | ตาราง / คอลัมน์ที่เกี่ยวข้อง |
|---|---|---|---|
| **วางบิล** | Billing / Invoice | บันทึกค่าขนส่งของงานหนึ่งใบ พร้อมรูปบิลและสถานะอนุมัติ | `ข้อมูลการวางบิล` (45 คอลัมน์) · `ปริ๊นใบวางบิล` (11) · `ID_วางบิล` · `รูปถ่ายบิลงาน` |
| **ปริ๊นใบวางบิล** | Print Invoice | คิวสั่งพิมพ์ใบวางบิลแยกตามชื่องาน/คลัง | `ปริ๊นใบวางบิล`, `ID_ปริ๊นใบวางบิล`, `ปริ๊นใบวางบิลแยกตามชื่องาน` |
| **ใบป่ะหน้า** | Delivery Note / Waybill | เอกสารที่พนักงานขับนำไปมอบสินค้า สร้างเป็น XLSX รายคน | `PDFพนักงาน`, `ปริ๊นใบป่ ะหน้า`, `ID_XLSXพนักงาน`, `ชื่อไฟล์`, `Export to XLSX` · บอท `ใบป่ ะหน้า - 1` |
| **สแกน** | Scan (E-POD) | สแกนรับเอกสารของงานที่ส่งถึงจุดส่งแล้ว | `ScanDocs`, `Scan_Invoice`, `Select_Invoice`, `Scan_DateTime`, `Scan_By`, `Scan_Method`, `ScanStatus` |
| **E-POD** | Electronic Proof of Delivery | เอกสารยืนยันการส่งมอบสินค้าแบบอิเล็กทรอนิกส์ (นับเป็นใบที่ต้องสแกน) | `ตารางงานประจำวัน.จำนวน_Invoice_ที่ต้องสแกน` · `สรุป_Shipment.จำนวน_E-POD_ทั้งหมด` · `สรุป_เจ้าของสินค้า.จำนวน_E-POD_ทั้งหมด` |
| **เบิกส่วนต่าง** | Expense claim / Variance claim | เมื่อค่าขนส่งจริง **มากกว่า** ราคาที่ระบบคำนวณได้ → ขอเบิกส่วนต่าง | `ทำเบิกส่วนต่างScgวังน้อย` (136 คอลัมน์) · `ขออนุมัติเบิกค่าขนส่งส่วนเพิ่ม` · `สรุปเบิกส่วนต่าง` · `รวมค่าขนส่งส่วนเพิ่ม` |
| **ค่าขนส่ง** | Transportation cost | ค่าใช้จ่ายการขนส่งทั้งหมดที่ต้องเรียกเก็บ/เบิกคืน | `ราคา`, `ราคาตามระยะทาง`, `ราคาจุดเพิ่ม`, `ราคาเพิ่ม`, `ราคาหลังส่งสินค้า`, `ราคาที่อนุมัติแล้ว` |
| **คืนสินค้า** | Product return / Take-back | กรณีรับสินค้าคืนจากจุดส่ง มีค่าชดเชยเพิ่มตามสถานะ | `รับงานคืนได้เงิน200` · `สถานะการเข้ารับสินค้า` · `เลขที่เอกสารรับคืน` · `รูปบิลรับคืน` |
| **ประกาศ / รับทราบ** | Announcement / Acknowledgement | ผู้บริหารประกาศ พนักงานกดรับทราบและลงชื่อ | `Announcements`, `Acknowledge_Logs`, `ID_ประกาศ`, `เลือกเพื่อยืนยัน`, `ลงชื่อพนักงาน` (Signature) |
| **เอกสาร** | Document / Export | การส่งออกข้อมูลเป็นไฟล์ (xlsx / PDF) | `สร้างเอกสาร`, `Export to xlsx`, `Export to XLSX`, `EXPORT TO PDF`, `EXPORT TO Excel(สรุปจำนวนจุดส่งงาน)` |
| **งานประจำวัน** | Daily job schedule | ตารางงานที่ขับต้องทำในแต่ละวัน | `ตารางงานประจำวัน`, `Plan Delivery`, `ID_งานประจำวัน`, `DeliveryStatus` |
| **จุดส่งงาน** | Delivery point / Drop point | จุดที่ต้องไปส่งสินค้าในหนึ่งงาน | `จำนวนปลายทาง_System`, `รายชื่อปลายทาง_System`, `จำนวนจุดที่ส่งจริง`, `จุดส่งงานลำดับสุดท้าย` |

## 2. ศัพท์ด้านราคา

| ไทย | อังกฤษ | หมายถึงในแอปนี้ | ตาราง / คอลัมน์ |
|---|---|---|---|
| **ราคา** | Price | ค่าขนส่งที่ตกลงกับลูกค้า | `ข้อมูลการวางบิล.ราคา` (Initial value, แก้ได้) · `Price_Table.Price` |
| **เรทดีเซล** | Diesel rate | ราคาน้ำมันที่ใช้คำนวณราคาของวันนั้น | `ข้อมูลการวางบิล.เรทดีเซล` (App formula) · `ทำเบิกส่วนต่างScgวังน้อย.เรท น้ำมันดีเซล` · `ราคาน้ำมันดีเซล.ราคา/หน่วย` |
| **ราคาตามระยะทาง** | Distance-based rate | ราคาจากตารางเรท เลือกตามชื่องาน × ช่วงเรทน้ำมัน × ช่วงระยะทาง | `ข้อมูลการวางบิล.ราคาตามระยะทาง` · `Price_Table.เรทน้ำมัน_Minimum/Maximum`, `ระยะทาง_Minimum/Maximum` |
| **ราคาจุดเพิ่ม** | Per-stop surcharge | ค่าเพิ่มตามจำนวนจุดส่งจริงที่เกิน 10 หรือ 11 จุด (คิดจุดละ 50 บาท) | `ข้อมูลการวางบิล.ราคาจุดเพิ่ม` · `ทำเบิกส่วนต่างScgวังน้อย.ราคาจุดเพิ่ม` |
| **ราคาเพิ่ม** | Extra charge | ค่าเพิ่มเฉพาะงาน (เช่น MeSpace, จองรถก่อน 14.00, เพิ่มแรงงาน 1 คน) | `ข้อมูลการวางบิล.ราคาเพิ่ม` · `เลือกเพิ่มเติม` |
| **ราคาในระบบก่อนส่งสินค้า** | System price before delivery | ราคาที่ระบบคำนวณได้ก่อนส่งสินค้า (ใช้เทียบกับราคาจริง) | `ราคาในระบบก่อนส่งสินค้า` (15 คอลัมน์) |
| **ราคาที่อนุมัติแล้ว** | Approved price | ราคาที่ผ่านการอนุมัติแล้ว (ไม่อนุมัติ = 0) | `ข้อมูลการวางบิล.ราคาที่อนุมัติแล้ว` |
| **ทับราคา** | Price override | กำหนดราคาน้ำมันพิเศษเป็นช่วงวันที่ + ชื่องาน | `PriceOverride` (`StartDate`, `EndDate`, `UsePriceDate`, `JobName`, `Note`) |
| **ราคาคงที่ / ระยะทางคงที่** | Fixed price / Fixed distance | ราคาหรือระยะทางที่กำหนดตายตัวต่อชื่องาน | `ข้อมูลชื่องานต้นทางปลายทาง.ราคาคงที่`, `.ระยะทางคงที่`, `.ประเภทการคำนวน` |
| **ยกขึ้นชั้น** | Upper-floor / upstairs handling | ร้านที่อยู่ชั้นบน ต้องคิดค่าขนส่งเพิ่ม | `ข้อมูลการวางบิล.จำนวนร้านที่ยกขึ้นชั้น` · `รับงานคืนได้เงิน200.สถานะการเข้ารับสินค้า` = `ทำเบิกค่ายกขึ้นชั้น` |
| **ค่ายกขึ้นชั้น** | Upstairs handling fee | ค่าเบิกเฉพาะกรณียกขึ้นชั้น | `ทำเบิกค่ายกขึ้นชั้น` (ทั้งในสไลซ์ `FILTER`, `สร้างเอกสาร` และบอท) |

## 3. ศัพท์ด้านการส่งและเส้นทาง

| ไทย | อังกฤษ | หมายถึงในแอปนี้ | ตาราง / คอลัมน์ |
|---|---|---|---|
| **ปลายทาง** | Destination | จุดที่ส่งสินค้าถึง | `จุดส่งสินค้าปลายทาง` · `ชื่อปลายทาง` · `ที่อยู่ปลายทาง` · `สถานที่ส่งงาน (ปลายทาง)` |

| **ระยะทางที่วิ่ง** | Distance travelled (KM) | ระยะทางจริงที่ขับวิ่ง หน่วย กม. | `ข้อมูลการวางบิล.ระยะทางที่วิ่ง (KM)` |

| **รหัสลูกค้า** | Customer code | รหัสลูกค้า/เจ้าของสินค้า ใช้เชื่อมกับ `ข้อมูลงานRT` | `SCGภูมิภาค.รหัสลูกค้า` · `รับงานคืนได้เงิน200.รหัสลูกค้า` · `Doc_Return.รหัสลูกค้า` |

## 5. ศัพท์ด้านบุคคลและสิทธิ์

| ไทย | อังกฤษ | หมายถึงในแอปนี้ | ตาราง / คอลัมน์ |
|---|---|---|---|
| **พนักงาน** | Employee / Driver | ผู้ใช้งานแอป (ขับรถ/ส่งของ) | `ข้อมูลพนักงาน` (17 คอลัมน์) · `ID_พนักงาน` · `ชื่อ - นามสกุล` |

## 8. คำที่ “ข้อมูลในเอกสารไม่ระบุ”

| คำที่ถามมา | ผลการค้นในข้อมูลที่สกัดมา |
|---|---|
| **ชิปปิ้ง (Shipping)** | **ไม่ปรากฏเลย** (0 ครั้งในไฟล์ทั้งหมด) — ใกล้เคียงที่สุดคือ `โอนคลัง` |
| **ผู้รับงาน** | **ไม่ปรากฏเลย** — ใช้ `ผู้รับเหมา` แทน |
| **สตีลเบล** | ปรากฏเป็น `สตีเบล` (21 ครั้ง) เป็นชื่อคลัง/ลูกค้า — `สตีเบล เอลทรอน เอเซีย จํากัด` |
| ความหมายของ “JWD” | ข้อมูลไม่ได้ขยายคำย่อนี้ — ปรากฏเฉพาะในชื่อตาราง/คอลัมน์ |
| จำนวนผู้ใช้จริง / จำนวนคนต่อบทบาท | **ข้อมูลไม่ระบุ** (มีอีเมลในเงื่อนไข `Show_If` แต่ไม่บอกว่าเป็นของใคร) |
| ราคา/น้ำมัน ณ วันที่ใด | **ข้อมูลไม่ระบุ** — เป็นข้อมูลรายวันในชีต (`ราคาน้ำมันดีเซล.วันที่`) |
| ข้อมูลในแถว (row data) ของตาราง | ไม่มีในเอกสารที่สกัด — มีแค่โครงสร้าง (ชื่อ/ชนิด/สูตร) เท่านั้น |
