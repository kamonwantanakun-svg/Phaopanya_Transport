### 4.1 [สูง] วิว 4/5 ที่สุ่มได้: หัว JSON ของ `View configuration` ไปติดกับ `Position` และหัวของค่าโดนตัด

ภาพหน้า 1755 (วิว `ตารางงานประจำวัน`) แสดง:
```
Position                menu
View configuration      {"ColumnWidth":"Default","EnableQuickEdit":true,"ColumnOrder":
                         ["LatLong_Actual","Invoice No","ID_งานประจำวัน", ... ],"GroupBy":[ ... ],
                         "GroupAggregate":"MAX :: จำนวนปลายทาง_System","SortBy":[ ... ], ... }
```
ข้อมูลที่สกัดได้:
```
Position           = 'menu {"ColumnWidth":"Default","EnableQuickEdit":true,"ColumnOrder": ["LatLong_Actual", ...'
View configuration = 'นี้","น้ำหนักสินค้ารวมของร้านนี้", ... "MenuOrder":1}'
```
