## 1. บทบาทสองบทบาท

`ข้อมูลพนักงาน.ROLE` เป็นคอลัมน์ชนิด `Enum` ที่ PDF หน้า 280 พิมพ์ค่าไว้ว่า
`["ADMIN","USER"]` — ทั้งแอปใช้ `USERROLE()` ในสูตรระดับตาราง และใช้ `USEREMAIL()`
ผูกแถวกับผู้ใช้

| บทบาท | สิทธิ์โดยรวม | ตัวอย่างงาน |
|---|---|---|
| `ADMIN` | เห็นข้อมูล **ทั้งหมด** ของทุกคน แก้ไขได้ทุกตาราง | อนุมัติราคา · ตั้งค่าเรท/ราคา · ออกเอกสาร · สั่งบอท |
| `USER` | เห็น/แก้ได้เฉพาะ **แถวของตัวเอง** ในตารางที่กำหนด | บันทึกงาน · สแกนรับเอกสาร · แจ้งปัญหา · รับทราบประกาศ |

> `ROLE` ใน `ข้อมูลพนักงาน` คือ “ข้อมูลที่ประกาศไว้” ส่วน `USERROLE()` คือ “สิทธิ์ที่แอปบังคับใช้จริง”
> ทั้งสองต้องตรงกันที่ผู้ดูแลระบบตั้งค่าใน AppSheet

## 3. ชั้นที่ 2 — ระดับตาราง: `Security filter` (7 ตาราง)

ทุกตารางใช้นิพจน์เดียวกัน — `[data/formulas/formulas.csv]`

```
=OR(USERROLE() = "ADMIN", [Email พนักงาน] = USEREMAIL())
```

| # | ตาราง | หน้า |
|---:|---|---:|
| 1 | `SCGนครหลวงJWDภูมิภาค` | 2 |
| 2 | `ข้อมูลการเข้าบำรุงรักษา` | 3 |
| 3 | `ข้อมูลการวางบิล` | 3 |
| 4 | `ตารางงานประจำวัน` | 4 |
| 5 | `แจ้งปั ญหาระหว่างวัน` | 7 |
| 6 | `รับงานคืนได้เงิน200` | 8 |
| 7 | `ทำเบิกส่วนต่างScgวังน้อย` | 3 → 12 |

**ความหมาย:** ADMIN เห็นทุกแถว · พนักงานเห็นเฉพาะแถวที่ `Email พนักงาน` ตรงกับที่ล็อกอิู่
→ นี่คือกลไกที่ทำให้ “พนักงานเห็นเฉพาะของตัวเอง” ใน 7 ตารางที่แกนของกระบวนการ

> **ข้อสังเกตเชิงออกแบบ:** ทั้ง 7 ตารางนี้เป็นตารางที่มีข้อมูล **อ่อนไหวทางการเงิน**
> (`ข้อมูลการวางบิล`, `รับงานคืนได้เงิน200`, `ทำเบิกส่วนต่างScgวังน้อย`) —
> แต่ `สรุปเบิกส่วนต่าง`, `FILTER`, `ปริ๊นใบวางบิล`, `PDFพนักงาน`, `ราคาในระบบก่อนส่งสินค้า`
> ที่มียอดเงินรวม **ไม่มี** Security filter — พนักงาน USER อ่านได้ทั้งที่ update mode เป็น READ_ONLY
> (ดูหัวข้อ 5 ใน `10-known-issues.md`)

### 4.2 กฎระดับคอลัมน์ที่ **ไม่** เกี่ยวกับสิทธิ์ (187 คอลัมน์ `Show_If` ที่ไม่มี `USERROLE`)

| แสดงเมื่อมีรูปครบ | `SCGภูมิภาค.หมายเหตุ` → `=AND(ISNOTBLANK([รูปถ่ายบิลส่งสินค้า]), ISNOTBLANK([รูปสินค้าตอนส่ง]), ISNOTBLANK([รูปหน้าร้าน / บ้าน]))` | — |
| แสดงตามชื่องาน | `ข้อมูลการวางบิล.ราคาเพิ่ม` → `=[ชื่องาน] ="MeSpace"` | — |
| แสดงตามธง “ระบุ…” | `ข้อมูลการวางบิล.รูปถ่ายใบเสร็จน้ำมัน_ใบเล็ก` → `=[ระบุการเติมน้ำมัน] = TRUE` | — |
